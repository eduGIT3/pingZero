# Iniciar el proyecto
## Backend
Ejecutamos el comando `mvnw.cmd spring-boot:run` en la terminal.  
La dirección del backend es `http://localhost:8080`. A esto le agregamos `/products` o la pagina a la que queramos acceder. 

### Base de datos: 
Para acceder a la consola de la base de datos usamos esta dirección: `http://localhost:8080/h2-console`.

>**DBC URL:**  jdbc:h2:mem:pharmacydb

## Frontend
Ejecutamos `ng serve` para iniciar el proyecto.
